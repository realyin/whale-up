# 专注守护 路线图

目标：从“计时器”升级为个人行为教练，形成 **记录 → 理解 → 干预 → 复盘** 的闭环。

```
浏览器扩展 / App 监测 ──► 内容记录（本地 SQLite）──► 大模型分析 ──► 日报 / 周报
          ▲                                             │
          └──── 个性化劝导、强制关闭、目标管理 ◄──────────┘
```

## 已定的决策

| 问题 | 决定 |
|---|---|
| 分析哪些网站 | 可配置：`off`（不记录内容）/ `junk`（只记录没营养网站，默认）/ `all`（全部网页） |
| 用哪个大模型 | 可配置：服务商（Anthropic / DeepSeek / OpenAI 兼容接口 / 本地 Ollama）、打标签用的模型、写报告用的模型 |
| 浏览器 | 先做 Chrome 扩展，之后做 Safari |
| API Key | 存系统钥匙串，不写进配置文件 |

## 阶段

### 第 1 阶段：内容记录（已完成）

- Chrome 扩展：记录每个视频 / 网页的标题、作者、标签、简介、实际观看时长
- 扩展 → 本机 App（只监听 127.0.0.1），按分析范围过滤后存入本地 SQLite
- 劝导弹窗上一键记录“为什么在刷”（累了 / 无聊 / 逃避 / 放松）
- 统计窗口能看到记录下来的内容
- 配置里加入分析范围和大模型设置（大模型第 2 阶段才使用）

不做：下载视频、截屏、读取网页正文全文。

### 第 2 阶段：大模型分析（已完成）

- ✅ 单条内容判断：有没有营养、营养分、主题、钩子类型、理由；判断结果覆盖网站规则，用于提醒、强制关闭和时长统计
- ✅ 服务商与模型可配置（Anthropic / DeepSeek / OpenAI 兼容 / Ollama），用户可写自己的标准
- ✅ 每日小结：主题、易刷时段、原因、“今天往脑子里装了什么”、明天试试
- 视情况加入字幕 / 文字稿

### 第 3 阶段：智能劝导（已完成）

- ✅ 劝导文案由大模型结合本次内容、时间、原因实时生成；超时或断网用固定文案
- ✅ 记录每次劝导的结果（接受 / 再刷 / 理由），写劝导和小结时参考哪种说法有效
- 弹窗内可以简单对话

### 第 4 阶段：行为管理与复盘（已完成）

- ✅ 每周复盘：模式、原因、需要加强什么、有营养的替代、下周承诺；写入 Obsidian
- ✅ 每日额度与工作时段
- ✅ 逐级干预：提醒 → 倒计时 → 写理由 → 强制关闭；可选“打开前先停一下”
- ✅ Safari 扩展
- 替代行动清单、每周承诺的完成检查

### 第 5 阶段：个人上网助理（进行中）

定位：从“防沉迷”升级为**个人上网助理 / 注意力账本**——把“看了什么、为什么看、学到什么、该少看什么”放在同一份数据上，回答“我的注意力花在了哪、换回了什么”。

原则：

- **核心循环只有一个：看见 → 理解 → 少刷一点 / 多学一点。** 不能缩短这个循环的功能先不做
- **记录和判断自动，沉淀要手动。** 有营养的内容由用户点“收进知识库”才进 Obsidian，避免笔记堆积和“刷视频也是学习”的错觉
- **隐私优先。** 敏感网站（银行、邮箱、医疗……）连标题都不记；全量时间线只在本地；可一键删除某天或某网站的记录；发给大模型的只有判断所需字段

步骤：

1. ✅ 时间线视图 + 敏感网站黑名单 + 按天 / 按网站删除记录
2. 内容要点提取：对收藏的内容抓字幕 / 正文，大模型提炼 3–5 个要点
3. 一键收进知识库：按 Wiki 的 Sources 格式写入 Obsidian，可接 knowledge-compiler 编译成卡片
4. 月度报告：这个月注意力换回了什么、模式有没有变、上月承诺是否做到
5. 改名与重新定位（“上网助理 / 注意力账本”）

衡量标准：每晚的小结用户愿不愿意读。
