# 专注守护 路线图

目标：从“计时器”升级为个人行为教练，形成 **记录 → 理解 → 干预 → 复盘** 的闭环。

```
浏览器扩展 / App 监测 ──► 内容记录（本地 SQLite）──► 大模型分析 ──► 日报 / 周报
          ▲                                             │
          └──── 个性化劝导、强制关闭、目标管理 ◄──────────┘
```

## 已定的决策

| 问题 | 决定 |
|---|---|
| 分析哪些网站 | 可配置：`off`（不记录内容）/ `junk`（只记录没营养网站，默认）/ `all`（全部网页） |
| 用哪个大模型 | 可配置：服务商（Anthropic / OpenAI 兼容接口 / 本地 Ollama）、打标签用的模型、写报告用的模型 |
| 浏览器 | 先做 Chrome 扩展，之后做 Safari |
| API Key | 存系统钥匙串，不写进配置文件 |

## 阶段

### 第 1 阶段：内容记录（进行中）

- Chrome 扩展：记录每个视频 / 网页的标题、作者、标签、简介、实际观看时长
- 扩展 → 本机 App（只监听 127.0.0.1），按分析范围过滤后存入本地 SQLite
- 劝导弹窗上一键记录“为什么在刷”（累了 / 无聊 / 逃避 / 放松）
- 统计窗口能看到记录下来的内容
- 配置里加入分析范围和大模型设置（大模型第 2 阶段才使用）

不做：下载视频、截屏、读取网页正文全文。

### 第 2 阶段：大模型分析

- 单条内容打标签：主题、营养分 1–5、吸引人的钩子类型（小模型）
- 每日小结：主题分布、易刷时段、触发场景、“今天往脑子里装了什么”
- 发送前可查看将要发出的内容；可随时关闭；支持本地模型
- 视情况加入字幕 / 文字稿

### 第 3 阶段：智能劝导

- 劝导文案由大模型结合本次内容、时间、目标、过往原因实时生成；超时或断网时用固定文案
- 记录每次劝导的结果（接受 / 再刷），学习哪种语气有效
- 弹窗内可以简单对话

### 第 4 阶段：行为管理与复盘

- 每周深度复盘（大模型）：模式、原因推断、需要加强什么、替代内容；可写入 Obsidian
- 目标与预算（每日额度、工作时段）
- 逐级干预：提醒 → 打开前等待 / 写理由 → 强制关闭
- 替代行动清单、每周承诺与回顾
- Safari 扩展
