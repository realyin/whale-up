# 凌晨两点还在刷视频，我给电脑做了一个会施法的大肥鱼

睡前刷视频，说好“最后一个”，再抬头已经两点了。电脑上更容易停不下来：开着 B 站本来是学东西的，学着学着就点进了推荐。

屏蔽网站的插件不少，可要么一刀切全封掉，要么弹个提醒，随手就关了。我想要的不是一个管我的工具，是一个会盯着我、但又不招人烦的东西。于是做了大肥鱼。

（这里放图 / 宣传片）

大肥鱼平时趴在屏幕右下角，眨眨眼，摇摇尾巴。到了饭点她会捧着一大碗米饭开吃，坐太久了她伸个懒腰，人走开了她就睡着，回来时打个哈欠。

刷视频刷久了，她会探出头说一句：“你已经刷了 47 分钟了哦。”要是点了“再刷 5 分钟”，她会鼓起脸，飞到浏览器上挥一下魔杖，网页就关了。

她能分清你在看什么。接上大模型以后，同样是 B 站，看 Swift 教程她不管，看猫猫翻车合集她才开始盯着你。哪些网站算没营养、每天能刷多久，都可以自己设。

想管得更狠一点，可以开强制关闭。比如抖音一天 30 分钟，用完了当天就打不开，打开一次关一次。真想多看，得自己去设置里加时间。

每天晚上她会写一段很短的小结，比如“深夜的抖音是今天唯一的失守”，再给一条第二天能做的小建议。小结和每周的复盘可以直接存进 Obsidian。

记录全都存在自己电脑上。银行、邮箱这类网站默认连标题都不记。只有开了 AI 判断，才会把网页标题发给你自己选的大模型，Key 也是你自己的。

现在只有 Mac 版，配合 Chrome 扩展使用，Safari 也行。代码开源了，目前要自己编译，步骤在 README 里：

https://github.com/realyin/whale-up
