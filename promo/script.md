# 「鲸醒」宣传短片脚本

B 站横屏 16:9，1920×1080，30fps，约 69 秒。搞笑卖萌向。背景音乐由 scripts/bgm.py 合成，可以换成自己的。
主角：大肥鱼（鲸鱼女仆），配音用 edge-tts 晓伊。画面就是一个二次元风的 Mac 桌面，她和真实 App 里一样待在右下角。
